# Lunoir Oracle Project

Build a premium, elegant, responsive website for a tarot reading brand called "Lunoir Oracle".

IMPORTANT:
This is a real client project. Do not create a generic AI-generated tarot website. The design must feel intentional, premium, editorial, sophisticated, mystical and luxurious.

BRAND
Brand name: Lunoir Oracle

Instagram:
https://www.instagram.com/lunoir.oracle/

Email:
lunoiroracle@gmail.com

The attached/reference logo is the primary brand identity. Preserve the logo exactly and do not redesign it.

VISUAL DIRECTION
Use the client's logo and attached visual references as the primary inspiration.

Overall aesthetic:
- Luxury mystical
- Elegant
- Minimal
- Editorial
- Feminine but not overly decorative
- Sophisticated spiritual brand
- Premium rather than "fortune teller"
- Soft, atmospheric and calm

Color palette:
- Deep black / near-black
- Warm ivory / cream
- Champagne gold
- Soft beige
- Dark brown

Suggested colors:
#161416
#F5EDE3
#C59A5B
#E7D8C7
#30241F

Do not overuse gold.
Do not use neon purple.
Do not use excessive gradients.
Do not use cartoonish zodiac graphics.
Do not use cheesy psychic/fortune-teller imagery.

TYPOGRAPHY
Use an elegant high-contrast serif typeface for major headings and a clean modern sans-serif for body text and UI.

The typography should feel like a luxury editorial/fashion/spiritual brand.

LAYOUT
Use generous whitespace.
Use strong visual hierarchy.
Use subtle borders.
Use refined card layouts.
Use restrained celestial motifs such as stars, crescent moons and thin-line ornaments.
Do not fill every empty space with decoration.

RESPONSIVENESS
The website must be fully responsive:
- Desktop
- Tablet
- Mobile

Mobile design is extremely important because the client's audience will likely come from Instagram.

NAVIGATION

Desktop:
Logo on left.

Navigation:
Home
Readings
How It Works
About
Reviews
FAQ

Right-side CTA:
BOOK YOUR READING

Mobile:
Logo
Hamburger menu
Prominent BOOK YOUR READING CTA

IMPORTANT BOOKING BEHAVIOR:
There is NO booking system.
There is NO calendar.
There is NO payment gateway.
There is NO customer account.

When the user clicks any booking CTA, redirect them directly to:

https://www.instagram.com/lunoir.oracle/

Open Instagram in a sensible way for the device/browser.

The CTA should make it clear that booking happens through Instagram.

Use wording such as:
"BOOK VIA INSTAGRAM"
or
"GET YOUR READING"

Do not build a fake booking form.
